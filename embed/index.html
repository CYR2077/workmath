Embed one of these calculators

Copy the block below into any HTML page — a company intranet, a staffing agency's pay page, a personal blog. Each widget runs entirely in the visitor's browser, works offline once loaded, and keeps its formatting down to phone width.

All widgets are free. No account, no API key, no attribution required (it is appreciated and already included in the snippet).

Before you paste

The iframe pulls a single stylesheet and an ~5KB script from workmath.net. Nothing is written to storage except the visitor's chosen currency. If your site sets a strict Content-Security-Policy, allow frame-src https://workmath.net.

Heights above are tuned so nothing scrolls inside the frame at default font sizes. If you embed inside a narrow column, add height a little — the field rows stack below about 560px of container width.
